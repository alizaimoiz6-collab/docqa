How it works

Four steps. The last one is the point.

1
Upload
A PDF or text file is split into numbered passages that keep their page numbers.
2
Ask Claude
The document and the question go to Claude Opus 5.5.
3
Structured answer
The reply must match a fixed format: answer, confidence, and a passage + quote for each claim.
4
Verify in code
Each quote is matched against the passage it cites. Anything made up gets flagged ⚠️.

What I learned

Three lessons from shipping it.

1
Ask for structure, not prose.Typed, structured output makes an AI far easier to build on reliably.
2
Check the AI's work in code.Verifying every quote beats asking the model to "be careful".
3
Cap spending from day one.A public demo needs rate limits and a hard budget. Mine stops at $1/day.
